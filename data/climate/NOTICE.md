# Source and terms of the climate tables

These three tab-separated tables contain daily observations of the Korea Meteorological Administration (KMA),
Automated Synoptic Observing System (ASOS), 2005-01-01 to 2024-12-31:

| File | ASOS station |
| --- | --- |
| 안동태화_충적_CL.txt | 136 Andong |
| 산청산청_암반_CL.txt | 289 Sancheong |
| 남해남해_암반_CL.txt | 295 Namhae |

Columns: Date (YYYYMMDD), TEMP, RAIN (daily precipitation, mm), HUMID, HPA, WIND. Only RAIN is used.

Source: Korea Meteorological Administration, 기상청_지상(종관, ASOS) 일자료 조회서비스
(https://www.data.go.kr/data/15059093/openapi.do), accessed for this release on 2026-10-04.
Terms: Korea Open Government License Type 1 (공공누리 제1유형): reuse, including commercial use and modification,
is permitted with attribution of the source. These files are not covered by the CC BY 4.0 license of the other data.
The file names follow the project's site labels and are required by the record generator.
